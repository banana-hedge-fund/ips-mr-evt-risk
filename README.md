# ips-mr-evt-risk

Учебный проект (ИПС, департамент прикладной экономики, ФЭН НИУ ВШЭ): **адаптивное управление рыночными рисками mean-reversion стратегий с использованием EVT и VaR/CVaR**.

Упрощённый бэктест по пересечению свечей (без учёта ликвидности) на минутных свечах Binance USDⓈ-M Futures (BTCUSDT, ETHUSDT, DOGEUSDT), сравнение стратегии с риск-менеджментом и без, на окнах 2024 и 2026.

## Гипотезы

- **H1.** Доходности криптофьючерсов асимметричны и тяжелохвосты; гауссовы модели риска недооценивают экстремальные потери.
- **H2.** Эффективность MR зависит от рыночного режима; в периоды высокой волатильности риск-скорректированные показатели ухудшаются.
- **H3.** Методы EVT позволяют идентифицировать режимы повышенного хвостового риска.
- **H4.** Адаптивное управление параметрами на основе EVT снижает tail-risk без ухудшения (либо с улучшением) риск-скорректированной доходности.

## Данные

Binance USDⓈ-M Futures, минутные klines, месяцы 2024-03, 2024-08, 2026-01, 2026-04 по BTC/ETH/DOGE.
Источник: <https://data.binance.vision/>. Итого ~520 тыс. минутных наблюдений, пропуски 0%.

## Ключевые результаты

**H1 (тяжёлые хвосты).** Избыточный эксцесс 13–487 (при 0 у нормального), Jarque–Bera p≈0 во всех выборках; оценка формы GPD ξ≈0.20–0.41 (>0 — область Фреше). Гауссовый VaR_99 даёт долю нарушений ~1.2–1.6% вместо 1%; EVT-VaR_99 — ~0.97–1.03% (тест Kupiec). Согласуется с H1.

**H4 (сравнение с риск-менеджментом и без).** По 12 месяце-выборкам адаптивный оверлей:
- снижает **CVaR_99 в 12/12** случаев;
- снижает **max drawdown в 11/12**;
- улучшает **Sharpe в 7/12** (выраженно — в окне 2026).

| Год | Конфиг | Sharpe | Max DD | CVaR_99 | Итог доход |
|---|---|---|---|---|---|
| 2024 | baseline | -3.68 | -0.284 | 0.00489 | -0.205 |
| 2024 | adaptive | -4.26 | -0.262 | 0.00377 | -0.186 |
| 2026 | baseline | -6.20 | -0.236 | 0.00298 | -0.205 |
| 2026 | adaptive | -5.00 | -0.165 | 0.00224 | -0.130 |

Обе конфигурации убыточны — риск-оверлей не делает наивную MR-стратегию прибыльной, но последовательно снижает хвостовой риск и просадки.

## Воспроизведение

```bash
pip install -r requirements.txt
python scripts/fetch_binance.py        # либо положить .zip архивы в data/raw/
python -m src.run_all                  # результаты → results/
```

Архивы данных и PNG-графики не хранятся в репо (см. .gitignore); воспроизводятся одной командой.

## Структура

```
src/data_io.py        загрузка/целостность свечей
src/econometrics.py   дескриптивы, ADF/KPSS, Хилл, AR(1)/OU, GARCH
src/evt.py            POT/GPD, EVT-VaR/CVaR, Kupiec, Christoffersen, режимы
src/metrics.py        Sharpe/Sortino/Calmar/MaxDD/CVaR
src/backtest.py       упрощённый MR ± адаптивный риск-оверлей
src/run_all.py        оркестратор
scripts/fetch_binance.py  загрузка архивов
```

## Ограничения

Упрощённая учебная реализация (ИПС, основа для будущей ВКР): исполнение по close без модели ликвидности/проскальзывания, без market impact; EVT-порог и окна фиксированы. Расширение — в ВКР.
